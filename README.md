# JefeStack

Sitio web de **JefeStack**, pinturas escolares hechas con pigmentos vegetales: remolacha, espinaca, cúrcuma y café.

Proyecto de Ciencias y Español · Décimo A · San Diego Bilingual High School, Alajuela, Costa Rica.

Es una sola página (`index.html`), sin dependencias. Para verla, abra el archivo en el navegador.
